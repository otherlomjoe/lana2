Gallery Upload Access

Use the password below to access the upload form. This static-host version is a browser-side gate only; a production host should use a server-side login and database.

Upload a new image

Upload both a thumbnail for the gallery grid and a larger detail image for the artwork page. Both will be saved in your browser storage and added to the gallery automatically.

Recommended storage for a live host: MySQL or SQLite via PHP/Node, or object storage for files with a database record for metadata. JSON files are fine for lightweight static prototypes but are not ideal for large galleries or multi-user updates.
